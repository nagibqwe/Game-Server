RuoYi — это полностью адаптивная тема с плоским дизайном, разработанная на основе последней версии Bootstrap 3.3.6. Она использует популярную двухколоночную компоновку, современные технологии HTML5+CSS3 и предлагает множество мощных переиспользуемых UI-компонентов. Также включает последнюю версию jQuery (v2.1.1) и множество функциональных jQuery-плагинов. Подходит для любых веб-приложений: панелей управления, личных кабинетов, CMS, CRM, OA и других. Вы также можете глубоко кастомизировать её для создания более мощной системы.

Настройки параметров

Функциональность модальных окон можно настраивать через атрибуты данных или JavaScript. При использовании атрибутов данных добавьте data-, например data-backdrop="".

Название Тип По умолчанию Описание
backdrop boolean или string 'static' true Затемнение фона. Используйте 'static', чтобы затемнение не закрывало окно
keyboard boolean true Закрытие окна по клавише Esc
show boolean true Показать модальное окно после инициализации
remote path false

Рекомендуется использовать атрибуты данных или jQuery.load

Пример удалённого URL:

<a data-toggle="modal" href="remote.html" data-target="#modal">Нажмите меня</a>
