Пожалуйста, обновите ваш браузер, чтобы мы могли лучше обслуживать вас!

Вы используете устаревшую версию Internet Explorer (IE9 или ниже, либо браузер на его основе). До обновления браузера вы не сможете получить доступ к этому сайту.

Обратите внимание: поддержка Windows XP и устаревших версий Internet Explorer компанией Microsoft прекращена

С 12 января 2016 года Microsoft больше не предоставляет поддержку и обновления для версий IE ниже 11. Отсутствие критических обновлений безопасности делает ваш компьютер уязвимым для вирусов, шпионского ПО и других вредоносных программ, которые могут украсть или повредить ваши данные и информацию. Подробнее см. объявление Microsoft о прекращении поддержки устаревших версий Internet Explorer с 12 января 2016 года.
